# 桃金娘质量安全管理记录系统（微信小程序版）

这是“桃金娘质量安全记录小程序 / 质量安全管理记录系统”的微信小程序原生 MVP。项目已从原 Web H5 方案改为 `.wxml / .wxss / .js / .json` 文件结构，可用微信开发者工具直接打开。

## 技术栈

- 微信小程序原生框架
- JavaScript
- WXML / WXSS
- `wx.setStorageSync` / `wx.getStorageSync` 本地缓存
- 无后端 API、无服务器部署、无外部 CDN、无外部字体

## 功能范围

- 登录、修改密码。
- 填表人锁定为当前登录用户。
- 通用“责任人”字段已从录入界面移除，避免和填表人重复；业务字段如操作人、检验员、处理人、验收人保留。
- 记录编号由系统生成；记录显示名由表单名称、日期、批次/姓名等自动组合，不再要求用户填写“记录标题”。
- 备注统一放在表单最后一栏。
- 首页横向滑动展示原始 8 个业务模块。
- 模块页展示对应表单和最近记录数量。
- 原始 37 张表格全部保留在种子和映射中，并补充 3 张小程序核心表单。
- 支持 39 张手机录入表单新增、编辑、查看。
- 记录列表支持搜索和状态筛选。
- 状态流：草稿、已提交、已审核、已退回。
- 已提交和已审核记录不可直接编辑。
- 已审核记录可通过“发起更正”复制生成新草稿，原记录不会被覆盖。
- 删除为软删除；已审核记录不可删除。
- 默认记录日期按北京时间（Asia/Shanghai）生成。
- 单条记录 A4 黑白友好预览，并支持导出 Excel 兼容表格到小程序本地文件目录。
- 生产过程关键控制点记录支持“制曲”项目的 HACCP CCP 临界值校验、批次报告和报告导出。
- 产品类型覆盖干豆豉、即食豆豉两类。
- 出厂/检验相关表单预留第三方委托检验机构、报告编号、盐分、氨基酸态氮、水分、微生物和黄曲霉毒素字段。
- “每日质量安全检查记录”和“每周质量安全排查治理报告”使用原 Word 表格检查项文字，并以单选方式填写。
- 每日、每周检查表的登录人员显示为“自查人员”；每周 10.2 默认选择“不适用”。
- “厂区环境卫生检查记录”和“生产场所及设备设施卫生检查记录表”使用原 Word 检查项文字，并以“合格 / 不合格”单选方式填写，默认合格。
- “生产场所及设备设施卫生检查记录表”按更衣室、从业人员、食品接触面、防止交叉污染、生产用水、防虫灭害、有毒有害物质分类显示。
- “从业人员职业健康监护档案”的员工号排在第一位，新建时从 `000001` 开始按现有最大员工号递增，生成后可修改；从业时间、建档时间默认当天，录入员工号或姓名匹配到历史档案时会显示历史记录并带出历史从业时间、建档时间；该表填表人显示在字段最后。
- “从业人员职业健康监护档案”按纸质档案结构存储：姓名、性别、工作岗位、员工号、出生年月、从业时间、健康证号、家庭病史、建档时间、照片为档案主信息；检查时间、检查单位、检查项目、检查结果、采取措施、备注保存为同一档案下的 `healthChecks` 明细数组，可在录入页新增或删除多条检查记录。
- 该档案的总备注位于照片上传下方；健康检查明细中的“采取措施”和明细“备注”默认填“无”。
- 员工档案详情页提供“新增年度检查”入口，只填写一行年度检查明细并追加到原档案；检查时间默认当天，检查单位默认带出上一条检查单位，检查项目默认“健康证”，检查结果默认“正常”，采取措施和备注默认“无”。该入口可用于已审核档案，但只追加明细，不修改基础档案信息，并记录追加人和追加时间。
- 全部固定选项字段统一改为直接单选框，默认选择第一个业务正常项，例如合格、符合、正常、委托第三方。
- 全部表单已统一处理“无”默认值：备注、其他资料、其他问题、存在问题、纠正/纠偏/处置措施、异常处置、家庭病史、原因分析、处理结果等可空说明类字段默认填“无”；保存时如果仍为空，也按“无”保存。姓名、数量、日期、供方、产品名等业务实填字段不会被默认成“无”。
- 手机端不再单独填写“合格供方名录”；供方评价审核通过且结论为合格供方后，PC 端可由供方评价记录汇总导出合格供方名录。
- “供方评价表”按原 Word 表内容收集资料，包括供方基本信息、采购产品分类、营业执照/生产许可证、资质图片、出厂检验能力、信用评价、质量稳定性、交付及时性、服务情况、评价结论和审批意见。
- 采购计划、进货查验记录、原料验收记录、原辅材料采购台帐可引用供方评价表：产品字段从已登记合格供方评价记录中下拉选择，选中产品后自动带出供方、生产厂家等已有信息；同一产品有多个供方时，供方字段使用下拉菜单选择。
- 供应商与采购模块填表流程为“供方评价表 → 采购计划 → 进货查验记录 → 原料验收记录 → 原辅材料采购台帐”；进货查验记录由仓管员填写，原料验收记录由检验员填写。
- 供应商与采购关键字段已按业务要求设为必填：供方地址/联系人/联系电话/生产厂家/评价人/审批日期、采购计划名称、进货查验名称/供方/生产厂家/仓管员、原料验收批次/品名/生产厂家/生产日期/保质期/检验员、台账批次/名称/生产日期/保质期/供方/采购日期/检验员。
- 进货查验记录的批号默认按年月和 6 位流水号生成，例如 `202605000001`，从当月 `000001` 开始递增，生成后仍可手动修改。
- 原料验收记录增加“批次”下拉，只显示已进货但尚未验收的批次；原辅材料采购台帐增加“批次”下拉，只显示已验收但尚未入台账的批次。有可用批次时默认选数字最小的批次；没有可用批次时显示“暂无可选批次”。选择批次后会自动带出对应记录的规格型号、单位、数量、供方等信息，带出内容可继续修改。
- 原辅材料采购台帐在规格型号下方增加“单位”，检验员默认当前填表人且不可修改。

## HACCP CCP

“制曲”不是独立纸质表，而是原表“生产过程关键控制点记录”中的一个关键控制点项目。选择关键控制点名称为“制曲”时，表单包含：

- 温度记录（℃）
- 湿度记录（%）
- 制曲开始时间
- 制曲结束时间
- 操作人
- 临界值超标纠偏措施

当前确认的制曲临界值：

- 温度 ≤ 40℃
- 湿度 60% - 100%

当温度或湿度超标时，保存前必须填写纠偏措施。可在“我的 > HACCP CCP 报告”按批次生成报告。

## 打印说明

小程序本地版提供 A4 黑白友好预览页。用户点击“导出表格”后，小程序会在本地文件目录生成 `.xlsx` 文件并打开预览页；用户可在预览页右上角菜单保存或分享。

微信小程序不能像桌面浏览器一样直接写入任意“下载”目录，因此当前文件先保存到小程序本地目录，再通过系统预览页交给用户保存。相较 PDF，`.xlsx` 对中文和表格内容更稳定，也比旧式 `.xls` 更容易被微信预览识别。

## 本地数据说明

当前数据只保存在微信小程序本机缓存中：

- 用户：`tjn_users`
- 当前登录：`tjn_current_user`
- 记录：`tjn_records`
- 营业执照、生产许可证图片：保存到小程序本地文件目录，记录中保存本地文件路径

清理微信开发者工具缓存会清空本地账号和记录。上线前应切换为云开发数据库或自建后端 API，并补充权限、备份和审计。

当前版本包含一次性记录清理逻辑：下次启动小程序时会清空旧填写记录和记录关联的本地图片，但保留默认登录账号；清理完成后同一版本不会重复执行。

真机测试图片上传时，需要微信允许小程序使用相机/相册权限；正式小程序还需要在微信公众平台配置隐私保护指引，否则真机可能无法打开拍照或相册。
